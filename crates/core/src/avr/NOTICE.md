# avr8js

The files in this directory that say so are ported from
[avr8js](https://github.com/wokwi/avr8js) 0.21.1 (commit `bee6f0a`), Wokwi's
AVR emulator, and the test programs in `tests/programs.rs` were assembled from
its spec files with its own assembler. avr8js is distributed under the MIT
licence below. Its copyright notice and this permission notice go with every
copy of those files, whatever the licence this repository offers them under.
